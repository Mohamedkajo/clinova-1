# Clinova Documentation

## Purpose

This directory is the official documentation home for Clinova product, architecture, deployment, QA, and decision records.

## Sections

## Roadmap

Planning documents for upcoming releases, completed releases, milestones, and backlog items.

## Architecture

Templates for documenting system structure, database design, permissions, multi-tenant behavior, and security boundaries.

## Deployment

Operational templates for local development, production release, backup and restore, and server configuration.

## Product

Product-facing templates for vision, features, user roles, and role-specific responsibilities.

## QA

Manual and regression QA templates used before release and during stabilization work.

## Decisions

Architecture Decision Records documenting important technical and product decisions.
