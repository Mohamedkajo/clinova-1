# Clinova Documentation

## Purpose

This directory is the official documentation home for Clinova product, architecture, deployment, QA, engineering standards, changelog, and decision records.

## Sections

## Roadmap

Planning documents for upcoming releases, completed releases, milestones, and backlog items.

## Architecture

Documents for system structure, database design, permissions, multi-tenant behavior, and security boundaries.

## Deployment

Operational documents for local development, production release, backup and restore, and server configuration.

## Product

Product-facing documents for vision, features, user roles, and role-specific responsibilities.

## QA

Manual and regression QA documents used before release and during stabilization work.

## Standards

Engineering standards for coding, APIs, UI/UX, Git, testing, and the official engineering workflow.

Key files:

- `standards/Engineering_Workflow.md`
- `standards/Coding_Standards.md`
- `standards/API_Standards.md`
- `standards/UI_UX_Standards.md`
- `standards/Git_Standards.md`
- `standards/Testing_Standards.md`

## Changelog

Release-note structure for tracking unreleased work, release candidates, fixes, security notes, known issues, and upgrade notes.

Key file:

- `changelog/CHANGELOG.md`

## Decisions

Architecture Decision Records documenting important technical and product decisions.

## Documentation Rules

- Official documentation is written in English.
- Documentation should reflect implemented behavior unless clearly marked as planned.
- Do not document unapproved production procedures as completed.
- Keep decision records stable and append updates rather than rewriting history without reason.
